# AllTools Studio

A beginner-friendly React + Vite starter project with:
- Responsive dark homepage
- Searchable tool cards
- Browser-based PNG/JPG/WebP image converter
- Multiple image uploads and individual downloads

## Run locally

1. Install Node.js (LTS) if it is not already installed.
2. Open this folder in VS Code.
3. Open Terminal > New Terminal.
4. Run:

```bash
npm install
npm run dev
```

5. Open the local URL printed in the terminal, usually http://localhost:5173/

## Build

```bash
npm run build
```

Image conversion happens in the browser. Images are not sent to a server.
